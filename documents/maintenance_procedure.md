## 1. Purpose

This procedure describes the general maintenance workflow used in the
Industrial AI Operations Copilot demonstration.

The objective is to identify maintenance requirements, record maintenance
events, and analyze the relationship between equipment condition,
failures, downtime, and maintenance activity.

---

## 2. Maintenance Types

Two primary maintenance categories are represented:

### Preventive Maintenance

Preventive maintenance is performed based on equipment condition,
scheduled intervals, or predefined maintenance criteria.

### Corrective Maintenance

Corrective maintenance is performed following an equipment failure or
identified abnormal condition.

---

## 3. Maintenance Records

Each maintenance event contains information including:

- Maintenance ID
- Timestamp
- Equipment ID
- Maintenance type
- Failure mode
- Severity
- Tool wear
- Downtime
- Technician team
- Parts replaced
- Maintenance status

The equipment ID is used to associate maintenance events with the
corresponding equipment.

---

## 4. Maintenance Investigation

When investigating repeated equipment problems, review:

1. Recent failure events.
2. Historical failure frequency.
3. Downtime associated with failures.
4. Tool wear.
5. Previous maintenance events.
6. Maintenance type.
7. Failure mode.
8. Parts previously replaced.

Multiple data sources may need to be combined when investigating an
equipment issue.

---

## 5. Tool Wear and Maintenance

Tool wear is an accumulated condition indicator.

High tool wear may indicate an increased need for maintenance review,
but tool wear should not be treated as the only factor determining
maintenance requirements.

Maintenance history and equipment behavior should also be considered.

---

## 6. Failure Investigation

For a machine failure event, review:

- Equipment ID
- Failure timestamp
- Failure mode
- Tool wear
- Production conditions
- Downtime
- Previous maintenance history

A repeated failure mode should be investigated using historical
maintenance and production records.

---

## 7. Maintenance Completion

After maintenance activity:

1. Maintenance status should be updated.
2. Parts replaced should be recorded.
3. Relevant failure information should be documented.
4. Equipment availability should be confirmed.
5. Production should resume only after the equipment is cleared for use.
